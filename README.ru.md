# OrientMark QR

Генератор QR-кодов для приложений OrientMark: контрольные пункты 31–99, старт, финиш и очистка.
Работает на Windows 10/11 x64 без интернета.

Исходный код распространяется под лицензией [MIT](LICENSE).
Сторонние компоненты сохраняют свои лицензии:
[THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md#third-party-licenses).

# Пользовательская инструкция
## Установка приложения
Приложение не требует установки, достаточно скачать EXE-файл и запустить.
Нужную версию `OrientMark-QR-<версия>.exe` можно скачать со [страницы релизов](https://github.com/orient-mark/qr-generator/releases/latest)

Ссылка в приложении «Проверить версию приложения» открывает последний релиз на GitHub.

## Создание QR-кодов

1. Выберите контрольные пункты и служебные коды.
2. Выберите формат экспорта и параметры макета.
3. При необходимости включите русские подписи на QR-кодах.
4. Выберите папку и нажмите «Создать QR-коды» или «Создать PDF».

Результаты сохраняются в подпапку `OrientMark QR`.
Замена существующих файлов требует подтверждения.

Интерфейс доступен на русском и английском.
Переключатель языка расположен вверху окна.
Язык интерфейса и язык печатных подписей выбираются независимо.

## Экспорт и печать

- **PNG** — отдельное изображение для каждой выбранной точки.
- **QR на А4 · PDF** — 4, 6 или 8 кодов на странице.
- **Большая призма · PDF** — одна точка на листе, три грани.
- **Маленькие призмы · PDF** — две точки на листе.

Призмы доступны с клеевым клапаном, с прорезями и язычками или без креплений.
Предпросмотр позволяет просматривать и увеличивать страницы до сохранения.

Печатайте PDF в масштабе **100% / «Фактический размер»**.
Вырезайте по сплошным линиям, сгибайте по пунктирным.
Клеевой клапан приклеивается изнутри; язычки вставляются в прорези.

## Разработка

Требования:

- Windows 10/11 x64.
- Flutter 3.47+ и Dart 3.13+.
- Visual Studio с компонентом **Desktop development with C++** и Windows SDK.
- Режим разработчика Windows для символических ссылок Flutter-плагинов.

Клонирование и запуск в режиме отладки:

```powershell
git clone --branch dev https://github.com/orient-mark/qr-generator.git
cd qr-generator
flutter pub get
flutter run -d windows
```

Сборка без запуска:

```powershell
flutter build windows --debug
```

Обычная release-сборка:

```powershell
flutter build windows --release
```

Результат находится в `build/windows/x64/runner/Debug/` или `Release/`.
Для запуска нужна вся соответствующая папка, включая DLL и `data/`.

## Добавление языка интерфейса

1. Скопируйте `assets/l10n/en.json`, например в `assets/l10n/de.json`.
2. Переведите значения, сохранив ключи и параметры `{count}`, `{page}`,
   `{version}` и другие. Используйте JSON в UTF-8.
3. Добавьте элемент в существующий массив `assets/l10n/languages.json`:

```json
{"code": "de", "name": "Deutsch"}
```

Код языка должен совпадать с именем файла без расширения.
Используйте язык, поддерживаемый стандартной локализацией Flutter;
региональный вариант можно записать как `pt_BR`.
Сохраните базовые языки `ru` и `en`.

4. Перезапустите приложение через `flutter run -d windows` или пересоберите его.

Язык появится в переключателе автоматически.
Менять Dart-код и список ресурсов не требуется.
При загрузке проверяются ключи и параметры переводов.
Выбор языка действует до закрытия приложения и не меняет содержимое QR-кодов.

## Совместимость QR

Формат данных соответствует приложениям OrientMark:

```json
{"point":{"checkpoint":31}}
{"point":"start"}
{"point":"finish"}
{"point":"cleaning"}
```

Язык меняет только печатную подпись. QR-коды чёрно-белые, с защитным полем
в четыре модуля и коррекцией ошибок H.
